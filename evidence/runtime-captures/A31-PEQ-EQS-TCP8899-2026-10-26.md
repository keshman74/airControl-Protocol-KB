# A31 PEQ/EQS read-only verification (2026-10-26)

Status: **HW-VERIFIED + IMAGE-VERIFIED; no settings changed**.

Target: A31 `192.168.0.192`, firmware `4.6.415156`, hardware `A31`.

## Arylic TCP frame

Queries were sent to TCP/8899 using the documented frame: header `18 96 18 20`, little-endian payload length, little-endian byte-sum checksum, 8 reserved zero bytes, then payload.

## PEQ response

Request payload: `MCU+PAS+RAKOIT:PEQ&`

Response payload: `MCU+PAS+RAKOIT:PEQ:0@Flat,1@Classical,2@Pop,3@Jazz,4@Rock,5@Vocal&`

The A31 exposes six named EQ presets, indexed 0–5. This query does not expose ten independent band coefficients.

## EQS response

Request payload: `MCU+PAS+RAKOIT:EQS&`

Response payload: `MCU+PAS+RAKOIT:EQS:0&`

`EQS` reports the current preset index. The observed range is bounded by the PEQ list: 0–5. No ten-band structure was returned.

## Firmware inspection

The extracted `home/bin/hdl` contains handlers/strings for `PEQ`, `EQS`, `EQSet:treble:<n>`, `EQSet:bass:<n>`, and the ordinary `TRE`, `MID`, `BAS` controls. The image also contains preset names `Flat`, `Classical`, `Pop`, `Jazz`, `Rock`, `Vocal`. No strings or handler names for ten independent band parameters (`EQ1`…`EQ10`, per-band frequency/gain/Q, or equivalent) were found in the inspected A31 `hdl` image.

## Conclusion

This A31 firmware supports six EQ presets plus bass/middle/treble-style controls. A 10-slider UI can be implemented only as an application-side abstraction or preset mapper; a true ten-band device-side EQ is not evidenced by this firmware or by the PEQ/EQS responses. Physical DSP internals remain outside this network/API evidence.

Raw query responses were observed directly from the A31 and should not be generalized to A97/A98 without their own evidence.

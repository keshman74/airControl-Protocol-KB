# Registry

Master cross-device registry. The baseline contains **204 records**.

ID prefixes:
- CMD command
- QRY query
- EVT asynchronous event
- PROTO protocol
- DEV device/chip
- FUNC function
- SVC service
- RULE behavior/security rule
- TEST hardware test
- CAP capture
- SRC source/document
- REV reverse-engineering finding
- PRJ project
- CHAT research chat

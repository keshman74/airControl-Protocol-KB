# A33M HTTPS API V1.2 — complete canonical manual mapping

**Official source:** *HTTPS API for A33M User Manual V1.2*, 19 Jan 2026, 36 pages.
**Evidence:** DOCUMENTED / OFFICIAL-A33M-V1.2. Hardware status remains separate.
**Envelope:** HTTP `http://<ip>:8000/?Instruct=<params>`; HTTPS `https://<ip>:8443/?Instruct=<params>`. Responses are JSON or text.

This file maps **all 63 API entries in sections 3.1–3.13**. Existing canonical IDs are reused; only the previously missing `getEqSwitch` gets a new record.

## 3.1 Device information
### QRY-ACS2-STATUS — getStatusEx
Response JSON fields shown by the manual: `DevDate, DevTime, ProjectName, SN, UUID, DevName, UserDevName, BleName, Eth0Mac, Wlan0Mac, VERSION, NEW_VERSION, DevVolumeL, DevVolumeR, VolumeState, DevVolumeMax, TCPIP, NetworkMode, DevFunction[], EqType, EqEnable, USBModel, DevModel, StreamMediaName, PushMode, Shuffle, Repeat, A33M_OTA, MCU_OTA, SongPlay, Token, SongList, Path, TuneinId, PlayState, StreamSource, MultiroomType, MultiroomStatus, Host, AllMate`.
Rules: MultiroomType = `host|slave|none`; MultiroomStatus is normally `free` and `busy` during group operations; Host absent/no IP = none, Host==TCPIP = host, Host!=TCPIP = slave. Returns JSON or `Error`.

## 3.2 Network
- **QRY-ACS2-WIFI-STATE** `wlanGetConnectState` → `OK` connected / `FAIL` failed / `PROCESS` in progress.
- **QRY-ACS2-SCAN-APS** `getScanAPs` → scanned AP response; manual warns first request may not show APs and may need repeated refresh.
- **CMD-ACS2-CONNECT-AP** `connectToAP:wifiName:<name>:wifiPassword:<password>`. If SSID/password contains `#`, encode as `%23`. Never store real credentials.

## 3.3 Playback
- **QRY-ACS2-PLAYER-STATUS** `getPlayerStatus` → JSON `Device, PlaySource, LoopMode, PlayStatus, Track, Volume, Mute`. Device=`standalone|master|slave`; LoopMode 1 single, 2 list loop, 3 list no-loop, 4 random loop, 5 random no-loop; PlayStatus=`play|pause|stop`; Track=`total|left|right`.
- **CMD-ACS2-PLAY-URL** `setPlayerCmd:play:<url_info>`. `url_info` may be plain URL or JSON `{"Url":"xxx","Title":"xxx","Artist":"xxx","Album":"xxx","Picture":"xxx"}`; Url mandatory, metadata optional; URL-encoded JSON supported. Returns `OK|FAIL|Error`; FAIL=invalid URL.
- **CMD-ACS2-PLAYLIST** `setPlayerCmd:playlist:<songid>` → `OK|Format|Not found|Not|Error`; `Not` means source lacks feature; manual says switch to Tidal/Qobuz.
- **CMD-ACS2-PAUSE** `setPlayerCmd:pause` → `OK|FAIL|Consistent|Not|Error`.
- **CMD-ACS2-RESUME** `setPlayerCmd:resume` → `OK|FAIL|Consistent|Not|Error`.
- **CMD-ACS2-TOGGLE** `setPlayerCmd:onepause` → paused→resume, otherwise pause; `OK|Buffer|Close|Error`.
- **CMD-ACS2-PREV** `setPlayerCmd:prev` → `OK|FAIL|Not|Error`; manual lists qobuz/tidal/usbmusic/local/Bluetooth/airplay/share support.
- **CMD-ACS2-NEXT** `setPlayerCmd:next` → `OK|Not|Error`; same listed source family.
- **QRY-ACS2-POSITION** `setPlayerCmd:getplay:seconds` → JSON example `{"status":"setPlayerCmd:setplay:0s"}`; `Not|Error` possible. Manual lists qobuz/tidal/usbmusic/local/Bluetooth/share.
- **CMD-ACS2-SEEK-HTTP** `setPlayerCmd:setplay:<seconds>` → `OK|Format|FAIL|Not|Error`; FAIL=busy. Seeking beyond duration may end current song and advance.
- **CMD-ACS2-STOP** `setPlayerCmd:stop` → `OK|Error`.
- **CMD-ACS2-VOLUME** `setPlayerCmd:vol:<0..100 or configured max>` → `OK|Exceed|Format|Error`.
- **CMD-ACS2-CHANNEL** `setChannel:<rl|rr|ll>`: stereo/right/left → `OK|FAIL|Not|Error`.
- **CMD-ACS2-VOL-UP / CMD-ACS2-VOL-DOWN** `setPlayerCmd:RemoteVol++` / `RemoteVol--` → `OK|Exceed|Error`.
- **CMD-ACS2-MUTE** `setPlayerCmd:mute:<1|0>`; group playback also sets slave mute state. Success JSON example `{"status":"setPlayerCmd:mute:1"}`; `Format|Error`.
- **CMD-ACS2-MAX-VOLUME** `setPlayerCmd:maximumVolume:<10..100>` → `OK|Exceed|Format|Not|Error`.
- **CMD-ACS2-PROMPT-TONE** `setPlayerCmd:prompttone:<Enable|Disable>` → `OK|Format|Error`.
- **CMD-ACS2-LOOP** `setPlayerCmd:loopmode:<1..5>` using same loop map → `OK|FAIL|Error`.

## 3.5 USB
- **CMD-ACS2-USB-PLAY** `playFromUsbDisk` → `OK|Not|Error`; Not=no USB.
- **QRY-ACS2-USB-LIST** `getUsbSongList` → JSON object whose keys are numeric song IDs and values are `/udisk/...` paths; `Not|Error`.
- **CMD-ACS2-USB-SELECT** `selectUsbTracks:<usbSongNum>` → `OK|Format|Not found|Not|Error`.

## 3.6 Source switching
**CMD-ACS2-SOURCE** `setPlayerCmd:switchmode:<text>`. Official V1.2 strings: `Network`, `Bluetooth`, `USB Disk`, `Line In`, `Line2 In`, `Optical In`, `Optical2 In`, `HDMI ARC`, `PHONO In`, `AUX In`, `Coaxial In`. Availability depends entirely on hardware configuration. Returns `OK|FAIL|Not|Error`; FAIL=same mode or unavailable source, Not=no USB.

## 3.7 Bluetooth
- **CMD-ACS2-BT-DISCOVERY** `setDiscoveryBluetooth:<Open|Close>` → `OK|Format|Error`.
- **CMD-ACS2-BT-RESET** `resetBluetoothPairing` → `OK|Error`.
- **CMD-ACS2-BT-CLEAR** `clearBluetoothPairingList` → resets pairing first, then clears list; `OK|Error`.
- **QRY-ACS2-BT-NAME** `getBluetoothName` → JSON example `{"status":"getBluetoothName: WiFi Audio E8CC"}` or `Error`.
- **CMD-ACS2-BT-NAME** `modifyBluetoothName:<bleName>` → `OK|Error`.

## 3.8 Metadata
**QRY-ACS2-META** `getMetaInfo` → JSON fields `Title, Artist, Album, Picture, Schedule, Totlen, PlaySource`; example PlaySource=`tidal`. `Schedule` current progress, `Totlen` total duration. Returns JSON or `Error`.

## 3.9 Multiroom
- **CMD-ACS2-MR-HOST** `multiroom:setHost`: must designate master before adding slaves → `OK|FAIL|Error`.
- **CMD-ACS2-MR-SLAVE** `multiroom:setSlave:<host_ip>`: send only to corresponding slave → `OK|FAIL|Now_is_host`.
- **CMD-ACS2-MR-DISCONNECT** `multiroom:disconnectSlave`: send to slave → `OK|Error`.
- **CMD-ACS2-MR-BREAK** `multiroom:breakUp`: send to master → `OK|Error`.
- **QRY-ACS2-MR-INFO** `multiroom:getInformation` → JSON fields `HostIp, MyIp, SlaveSum, UserDevName, DevVolume, VolumeState, Version, groups[]`; shown group object has `group_count, connected_count`. `SlaveSum` host-only. Returns JSON / `Not_in_multiroom` / `Error`.

## 3.10 Prompt sounds
- **CMD-ACS2-PROMPT-DOWNLOAD** `downloadPromptSound:<audioFileName>`; accepts cloud-echo filename `xxx.wav` or HTTPS WAV URL → `OK|Format|Exceed|Exist|FAIL|Error`; max 20 prompt files.
- **CMD-ACS2-PROMPT-PLAY** `playPromptSound:<audioName>[:volume]`; volume 10..100, omitted volume defaults 50 → `OK|Format|Exceed|Not|Error`.
- **QRY-ACS2-PROMPT-SERVER** `viewServerPromptSound` → text list / `FAIL|Error`.
- **QRY-ACS2-PROMPT-DEVICE** `viewDevicePromptSound` → text list / `Not|Error`.
- **CMD-ACS2-PROMPT-DELETE** `deleteSpecifiedAudio:<audioPath>` → `OK|Format|FAIL|Not|Error`.

## 3.11 Static IP
- **CMD-ACS2-STATIC-SWITCH** `setNetIPSwitchState:<Enable|E_Enable|W_Enable|Disable>`: configure static IP first. Enable=eth0+wlan0, E_Enable=eth0, W_Enable=wlan0. Returns `OK|Format|FAIL|Error`.
- **CMD-ACS2-STATIC-IP** `setStaticIP:<JSON>`. Fields: `WStaticIp,WStaticNetmask,WStaticGateway,WStaticDns,EStaticIp,EStaticNetmask,EStaticGateway,EStaticDns`; WLAN-only or Ethernet-only subsets allowed. Manual recommends configuring both. Important routing rule: if only one interface has static configuration while the other is used dynamically, routing for the dynamic interface may be disabled and the app may stop finding the device. Returns `OK|FAIL|Error`.

## 3.12 EQ
- **QRY-ACS2-EQ-TYPE** `getEqType` → text; `0111` means EQ supported; `Error`.
- **QRY-A33M-EQ-SWITCH** `getEqSwitch` → text current EQ switch; values follow eqEnable map; `Error`.
- **CMD-ACS2-EQ-ENABLE** `eqEnable:<eqSwitch>`: `0000` off; `0001` high/low; `0010` preset; `0011` high/low+preset; `0100` parameter; `0101` parameter+high/low. Preset and parameter EQ cannot be simultaneously active, therefore `0110` and `0111` are unavailable. Returns `OK|Format|Not|Error`.
- **CMD-ACS2-EQ-HILO** `setEqHighAndLowFrequencies:{"Bass":"-5..5","Treble":"-5..5"}` → `OK|FAIL|Bass error|Treble error|Error`.
- **CMD-ACS2-EQ-PRESET** `setPresetEq:<JSON>`: `{"Custom":"x","Name":"xxx","EqBand":[10 values]}`; EqBand each -12..12 → `OK|FAIL|EQ disable|Custom error|Name error|EqBand error|Error`.
- **CMD-ACS2-EQ-PARAM** `setParameterEq:<JSON>`: Custom, Name, EqBand up to 10 points. Point fields: Index 0..9; Filter `PK|LS|HS|LP|HP|OFF`; Freq 20.0..24000.0; Q 0.0..30.0; Gain -12.0..12.0. Returns `OK|FAIL|EQ disable|Custom error|Name error|EqBand error|Index error|Filter error|Freq error|Q error|Gain error|Error`.
- **QRY-ACS2-EQ-INFO** `getEqInfo:<1|2|3|22|33>`: 1 high/low; 2 preset; 3 parameter; 22 custom preset list/nginx; 33 custom parameter list/nginx → JSON / `Not|Error`.
- **CMD-ACS2-EQ-ADD** `addCustomEqInfo:<JSON>`: Type 2 preset with 10-band EqBand, or Type 3 parameter with point objects → `OK|FAIL|Type error|Name error|Error`.
- **CMD-ACS2-EQ-DELETE** `delCustomEqInfo:{"Type":"2|3","Name":"xxx"}`: 2 preset, 3 parameter → `OK|FAIL|Type error|Name error|No name exists|Error`.

## 3.13 Presets
- **CMD-A33M-PRESET-ADD** `oneClickPreset:{"PresetNumber":"x","Overwrite":"yes|no"}`. 0 auto-finds empty slot; if none, overwrite from first only with yes. 1..12 explicit slot → `OK|FAIL|Format|Exceed|Error`.
- **CMD-A33M-PRESET-CHOICE** `choicePreset:<1..12>` → `OK|Not|Format|Exceed|Error`; Not=empty slot.
- **CMD-A33M-PRESET-PREV** `playPreviousPreset` → `OK|FAIL|Error`.
- **CMD-A33M-PRESET-NEXT** `playNextPreset` → `OK|FAIL|Error`.
- **CMD-A33M-PRESET-MOVE** `movePresetPosition:{"OldIndex":"x","NewIndex":"x"}` → `OK|FAIL|Error`.
- **CMD-A33M-PRESET-DELETE** `deletePreset:<0..12>`: 0 clears all, 1..12 one slot → `OK|FAIL|Format|Exceed|Error`.
- **QRY-A33M-PRESET-LIST** `getPresetListInfo` → JSON success / `Error`. **The manual publishes no JSON example/schema; do not invent it.**

# airALARM voice prompts

Two Ukrainian WAV prompts for A33 ACS2 hardware testing:

- `airalarm_alert.wav` — «Увага! Повітряна тривога!»
- `airalarm_clear.wav` — «Увага! Відбій повітряної тривоги!»

Format: PCM signed 16-bit, 16 kHz, mono. Hardware support for `downloadPromptSound` and `playPromptSound` on the target A33 is **not yet verified**.

Keep originals and document actual device responses after testing.
